# Gradient Minimal Login

这是一个基于 Material 3 风格的极简登录界面设计。

## 设计特点
- **渐变背景**：使用 Indigo 和 Violet 的柔和渐变，增加视觉层次感。
- **玻璃态效果 (Glassmorphism)**：登录卡片采用半透明背景与模糊滤镜，营造现代感。
- **响应式设计**：适配不同屏幕尺寸。
- **微交互**：按钮悬停缩放与阴影增强。

## 技术栈
- HTML5
- CSS3 (Flexbox, CSS Variables, Backdrop-filter)
- Google Fonts (Inter)
