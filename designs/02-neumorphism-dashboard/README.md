# Neumorphism Card Dashboard

这是一个基于新拟物化 (Neumorphism) 风格的仪表盘界面设计。

## 设计特点
- **软 UI (Soft UI)**：通过精确的阴影与高光处理，使元素看起来像是从背景中挤压出来的。
- **低对比度视觉**：使用接近背景色的元素，营造柔和、舒适的视觉体验。
- **现代布局**：包含侧边栏导航、统计卡片与项目网格。
- **交互反馈**：按钮点击时的凹陷效果 (Inset Shadow)。

## 技术栈
- HTML5
- CSS3 (Grid, Flexbox, Box-shadow)
- Google Fonts (Poppins)
