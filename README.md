## 🎨 独立作品集 (Independent Portfolios)

以下是已迁移至独立仓库的作品列表：

### 1. [Glassmorphism Music Player](https://github.com/Ava12131/glassmorphism-player)
基于磨砂玻璃质感的音乐播放器，结合霓虹色彩与强模糊背景，营造未来感。
- **状态**：已迁移至独立仓库
- **链接**：[访问仓库](https://github.com/Ava12131/glassmorphism-player)

### 2. [Neumorphism Card Dashboard](https://github.com/Ava12131/neumorphism-dashboard)
通过精确的阴影与高光处理，营造出柔和、具有 3D 质感的“软 UI”界面。
- **状态**：已迁移至独立仓库
- **链接**：[访问仓库](https://github.com/Ava12131/neumorphism-dashboard)

### 3. [Gradient Minimal Login](https://github.com/Ava12131/gradient-login)
渐变背景 + 玻璃态卡片 + 微交互 hover 效果，提升沉浸感。
- **状态**：已迁移至独立仓库
- **链接**：[访问仓库](https://github.com/Ava12131/gradient-login)
